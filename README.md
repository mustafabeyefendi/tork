# TORK Ön Muhasebe

Bu depo yalnızca **TORK Ön Muhasebe** programının kurulum dosyalarını ve otomatik güncellemelerini barındırır.

- En son sürümü indirmek için sağdaki **Releases** bölümünden `TORK-Kurulum-x.y.z.exe` dosyasını indirin.
- Kurulu programlar yeni sürümleri buradan kendiliğinden indirir ve kapanışta kurar.

Kaynak kod bu depoda yer almaz.
